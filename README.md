# Hypotenuse of a Triangle Calculator

## Description 
This program calculates the hypotenuse of a right triangle using an entered values for the length of the two shoter sides of the triangle

## How to Run
Download the file in Github to open the file. You will then be directed to the program itself. You can then press the green play botton on the top right of your screen to run the program,
then you will be asked to enter the length of the two shorter sides of the triangle.

## Input needed
Enter a number for the length of both:

- side a 
- side b




## Sample output

- The hypotenuse is: 10.63
